# Start Website Dev Server

Start the Nuxt development server for local testing.

Execute in background:
```bash
cd /home/sheldon/Projects/From\ The\ Hart/from-the-hart-tech-website
npm run dev
```

After server starts, report:
1. Server URL (typically http://localhost:3000)
2. Successful startup confirmation
3. Any errors during initialization
4. Note: Use Ctrl+C to stop the server when done
